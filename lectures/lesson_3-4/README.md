# Операционные системы и среды.

> [!IMPORTANT]
>
> Занятие 3 - 4 - Диагностика системы.
> Ваша задача - поэтапно создать программу на языке Python с использованием системных библиотек
> 

> [!TIP]
>
> Вам нужно создать консольное приложение которое работает с вашей ОС.
> Приложение может сообщать пользователю в консоль характеристики ОС.
> Вся информация которую приложение сообщает пользователю должна выводится поэтапно.
> Сохраните ваш код проекта в репозиторий и пришлите ссылку.

- [ ] создайте в `Pycharm` файл `system.py`.
- [ ] импортируйте в файл `system.py` библиотеку  `os`, `sys`, `platform`.
- [ ] создайте несколько переменных 
- [ ] сохраните в переменные результат работы любого из методов этих библиотек
- [ ] добавьте список для хранения переменных
- [ ] создайте меню для отображения задач для пользователя
- [ ] для ввода и вывода используйте только `sys.stdin` и `sys.stdout`.
- [ ] из списка предоставляйте результаты методов сохраненные в индексах списка.
- [ ] распечатайте результат работы функций ранее сохраненные в консоль.
