# Операционные системы и среды.

> [!IMPORTANT]
>
> Занятие 7 - 8 - Процессы и потоки.
> Ваша задача - поэтапно создать программу на языке Python с использованием системных библиотек
> 

> [!TIP]
>
> Вам нужно создать консольное приложение которое работает с процессами.
> Приложение может сообщать пользователю в консоль о запуске процессов и их ID.
> Вся информация которую приложение сообщает пользователю должна выводится поэтапно.
> Сохраните ваш код проекта в репозиторий и пришлите ссылку.

- [ ] создайте в `Pycharm` файл `process.py`.
- [ ] импортируйте в файл `process.py` библиотеку  `os`, `time`, `multiprocess`.
- [ ] создайте четыре функции и в каждой оповещение
- [ ] создайте переменные (2-3) и поместите в них результат вызова класса `Process`
- [ ] с помощью вывода в консоль сообщайте о ID каждого процесса
- [ ] создайте ожидания в каждой функции с помощью библиотеки `time`
- [ ] распечатайте результат работы функций ранее сохраненные в консоль.
